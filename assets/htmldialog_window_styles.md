**SketchUp 2023 or later on Windows / SketchUp 2027 or later on macOS**

| style | Always stays on top of SketchUp | Disappears when SketchUp loses focus | Smaller titlebar |
| --- | --- | --- | --- |
| <code>STYLE_DIALOG</code> | Yes | No | No |
| <code>STYLE_WINDOW</code> | Yes | No | No |
| <code>STYLE_UTILITY</code> | Yes | Mac - Yes, Windows - No | Yes |

| <code>STYLE_WINDOW</code> | No | No | No |
| <code>STYLE_UTILITY</code> | Yes | Mac - Yes, Windows - No | Yes |
